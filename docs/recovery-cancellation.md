# 0.9.2 中断任务取消修复

中断后可恢复的 partial 任务现在可以从页面取消。普通 succeeded/failed/cancelled 和不可恢复 partial 仍不能从取消按钮操作；queued/running 沿用原有取消流程。

同一任务正在发送恢复或取消请求时，两个按钮都暂时禁用，轮询更新不会重新启用它们。取消后主动重新读取任务与报告；请求返回时若用户已切换任务，不把旧任务状态写入新页面。网络失败后可以重试，后端继续保持幂等。

取消中断任务会关闭恢复入口、清除过时的中断错误码，并保留已有部分报告的结论、证据引用、角色用量及压缩统计。任务和报告使用相同的最新持久预算用量；报告补记取消说明。不重新调查，也不调用模型或工具。报告缺失时仅从保存的图状态生成部分结果。取消状态与报告仍由现有事务一起保存。

本轮只完成编译与静态检查，没有运行测试、浏览器、服务或模型。运行时竞态与浏览器交互仍待后续验收。具体检查见 [recovery-cancellation-compile.json](results/recovery-cancellation-compile.json)。

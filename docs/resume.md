# 简历素材（只写已实现，指标待实测）

**RepoLens：面向Python仓库的多Agent源码研读与证据审计工具**

- 基于Python、FastAPI与LangGraph实现代码/文档分工、模型评审和有限补查；调查共享调用、token、工具及时间预算。
- 固定仓库快照，结合AST、全文检索及可配置Milvus混合检索，将结构化结论绑定到可复核的源码/网页证据。
- 实现官方持久检查点、租约epoch隔离、累计预算和响应重放；提供独立worker、PostgreSQL、Redis唤醒与Docker Compose配置。
- 为明确登记的资料提供受限网页采集及MCP stdio只读工具，补充固定commit题集、逐题审计工件和人工评分报告流程。

以上描述代码实现范围，不代表已验证生产可用。当前0.8.0仅编译/静态检查，模型质量、真实服务联调与性能指标待验收。第三行不得改成“保证外部请求exactly-once”或“支持多活水平扩展”。

## 实测后才能补的字段

质量完成率、人工引用准确率、样本量/重复次数、P95、输入/输出token、共享建库成本和对比配置。必须保留对应run ID、固定语料、模型/预算、人工评分及失败记录；没有价格就写调用量/token，不填金额。当前所有数值留空，不能用模板百分比或早期合成记录代替。
